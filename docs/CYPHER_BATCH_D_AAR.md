# Cypher Batch D sandbox acceptance AAR

Version: `cypher-batch-d/2.0.0`. Scope is synthetic local evidence only; no Cloudflare, customer, production, deploy, push, or live connector action is authorized or performed.

The physical hard gate uses local Auth, Data, RPC, and Storage APIs to create two legitimately authenticated tenants plus a finalized private document, trusted upload/audit/outbox/checkpoint chain, artifact, storage receipt, and migration receipt. A custom-format logical dump of the complete `auth`, `private`, `public`, and `storage` schemas is restored into a new database in a fresh Supabase PostgreSQL container with no shared database volume; bytes are restored to a separately created object volume. Exact scoped per-table counts and canonical row hashes match, the object digest matches, migration-defined session/RLS helpers admit the minted owner and deny the minted other-tenant session, anon is denied, replay is idempotent, and RPO/RTO are measured. Cleanup runs in `finally`, and the evidence pass is conditional on independent verification that both container and volume are absent.

The authenticated browser hard gate passes all seven workflows against real `worker.js` and `lib/cypher-supabase-adapter.js`. Each control persists a checked transition: upload intent through verified Storage finalization; OCR extraction through validation and correction history; relationship confirmation; exception resolution; obligation aging to overdue; evidence package plus non-empty CSV/JSON/XLSX object bytes and export jobs; and secure local-emulator delivery with observed digest, attempt receipt, and delivered status. The network log contains the real `/api/cypher/v1` calls, while valid other-tenant and anon requests are denied and the browser contains no service key. Setup grants only named INSERT privileges and revokes them in `finally`.

The complete reset and rejection checklist passed: pgTAP 42, private Storage API, Vitest 59, deterministic 300-document OCR/OOXML corpus, authenticated pilot, three axe viewports, migration/physical restore, load/recovery, site/Worker/types, dry-run build, database lint/advisors, npm audit, diff check, and static no-D1/R2 mutation scan. Human correction timing remains explicitly deferred. Live connectors remain blocked and production DR/load/deploy still require separate authorization.
