# SHIRABE diagnostic delivery toolkit

Internal, local-first tooling for one bounded bilingual diagnostic. This area is not a public route, customer portal, connector runtime, or autonomous decision system.

## Commands

```powershell
node internal/shirabe-delivery/cli.mjs scaffold <directory> <engagement-id>
node internal/shirabe-delivery/cli.mjs validate <engagement.json>
node internal/shirabe-delivery/cli.mjs package <engagement.json> <output-directory>
node internal/shirabe-delivery/cli.mjs verify <package-directory>
node internal/shirabe-delivery/cli.mjs restore <package-directory> <empty-directory>
node internal/shirabe-delivery/cli.mjs delete-rehearsal <package-directory> <working-directory> <receipt.json>
node --test internal/shirabe-delivery/tests/*.test.mjs
```

The engagement file is the sole input. Material findings and workflow events must cite admitted evidence. Conflicts remain open or receive a named human disposition. ROI is deterministic and preserves measured, reported, estimated, projected, and unknown classes. Critical English and Spanish statements require identical semantic keys and numeric values.

No command deploys, contacts a provider, reads customer systems, admits memory, or approves a recommendation.

## Professional and design-partner readiness

`reviews/professional-review-checklists.json` and `reviews/SIGNOFF_MATRIX.md` prepare legal, privacy, tax/accounting, insurance, security and bilingual review. Every professional status remains pending until a named qualified reviewer supplies a dated scope and evidence reference. Automation cannot grant professional approval.

`reviews/design-partner-evidence-candidate.json` is intentionally failing. It cannot pass with synthetic evidence, even if every numeric threshold is populated. A real, authorized engagement, verified package, customer signoff, measured labor/cost, accepted findings and zero critical integrity failures are mandatory.
